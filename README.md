Afgelopen 2 weken hebben wij een website gemaakt waarin we foto's van al onze klasgenoten. In de website hebben we alle mugshots toegevoegd en kan je doorverwijsd worden naar de profile card van dat persoon.

Squad:
Roxy
Semih
Gijs

3 opvallende features:
- De filter functie om door een zoekbalk andere mensen op te zoeken.
- De meer laden knop. Standaart word er 4 foto's geladen, maar door op de knop "meer foto's" te drukken kan je alle foto's die we hebben toegevoegd zien. met een optie om minder foto's te zien
- Responsive maken van de website. Ik ben druk bezig geweest om alles goed te krijgen op zowel desktop, en mobiel.
