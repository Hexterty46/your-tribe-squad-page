header 

In de header kan je onze logo en navigaties vinden om snel verschillende delen van onze website te kunnen zien.

In de welkom staat onze logo met informatie over de website.

De zoekfunctie is bedoeld om snel je eigen naam, of natuurlijk andere mensene op te zoeken. Standaart zie je 4 foto's op de website, als je meer foto's wilt zien kan je op de knop "meer foto's" klikken.

Via alle mugshots kan je naar de profile card van de persoon waar je op heb geklikt. Ook docenten staan aan de onder kant.

Onderdaan de pagina zij je verschillende locaties op het HvA waar je rustig kan zitten werken of iets anders kunt doen.
